# 지능형 기업 의사결정시스템 연구그룹 홈페이지

2025년도 글로벌인문사회융합연구지원사업(연구그룹 지원형, 국내형) 연구그룹 홈페이지입니다.
과제번호 NRF-2025S1A5C3A01010737. 빌드 도구도 서버도 필요 없습니다.

## 1. 디자인 방향

이 연구그룹은 경영학, 회계학과 컴퓨터공학이 절반씩 참여합니다. 그래서 화면 전체를 **두 개의 잉크**로 짰습니다.

- 붉은색은 인문사회(회계, 조세, 경영), 파란색은 이공(인공지능, 양자기계학습)
- 두 잉크가 겹치는 자리인 보라색은 융합에만 씁니다. 연구팀 3, 양자기계학습, 의사결정 결과가 여기에 해당합니다
- 로고는 두 원이 겹쳐 가운데가 진해지는 형태이고, 상단 4px 띠에도 겹침 구간이 있습니다
- 연구자 사진 테두리, 데이터 모달리티 막대, 소식 분류가 모두 같은 색 규칙을 따릅니다

메인 화면 상단은 배너 대신 **연구 파이프라인 3단**입니다. 왼쪽은 흩어져 있는 기업 데이터, 가운데는 융합 분석, 오른쪽은 그 결과로 바뀌는 의사결정. 이 연구가 무엇을 하는지가 첫 화면에서 끝납니다.

글꼴은 고운바탕(제목), IBM Plex Sans KR(본문), IBM Plex Mono(수치와 라벨)입니다.

## 2. 파일 구조

```
.
├── index.html            메인: 파이프라인, 연구팀, 1차년도 성과, 연차 목표와 2차년도 일정,
│                              연구진, 게재논문, 소식, 참여기관
├── members.html          연구진: 연구팀별 필터, 사진과 명부 펼치기
├── publications.html     연구성과: 게재논문 / 주요 발표 / 학술대회 발표 / 수상 탭
├── news.html             소식: 분류 필터, 페이지, 상세 창
├── preview.html          네 페이지를 한 파일로 합친 미리보기 (배포에는 불필요)
├── README.md
└── assets
    ├── css/style.css
    ├── img/              연구진 사진 6장 (480×480 정사각)
    └── js
        ├── data.js       사이트의 모든 내용
        └── main.js       렌더링과 인터랙션
```

## 3. 내용 수정

모든 텍스트는 `assets/js/data.js` 한 곳에 있습니다. HTML은 건드릴 필요가 없습니다.

| 항목 | 키 | 설명 |
| --- | --- | --- |
| 과제 기본 정보 | `project` | 과제명, 과제번호, 기간, 연구비, 연락처, 키워드 |
| 연구 개요 | `overview` | 리드 문장, 본문, 차별성, 연구 환경 및 인프라 |
| 연구팀 | `teams` | 3개 팀의 이름, 설명, 세부 주제, 소속 연구자, 트랙 |
| 연차 계획 | `roadmap` | 연차별 기간, 연구목표, 팀별 과제, 마일스톤 |
| 2차년도 일정 | `schedule` | 기간, 담당 팀, 수행 내용 |
| 1차년도 성과 | `achievements` | 메인 화면 숫자 4개 |
| 성과 목표 | `outcomes` | 연차별 목표 수치 |
| 연구진 | `members` | 이름, 소속, 직위, 사진, 연구 분야, 역할, 실적 |
| 게재논문 | `publications` | 제목, 저자, 게재지, 연도, 색인, IF와 JCR, 초록 |
| 주요 발표 | `presentations` | 제목, 발표처, 시기, DOI, 연구개요 |
| 학술대회 발표 | `conferences` | 국내외 구분, 학술대회, 논문명, 저자, 발표일 |
| 수상 | `awards` | 수상 종류, 기관, 논문명, 수상자, 일자 |
| 소식 | `notices` | 구분, 제목, 날짜, 본문 |
| 참여기관 | `institutions` | 하단 기관 링크 |

### 지금 채워야 하는 것

1. **게재논문 저자**: 9편 중 Symmetry 논문 한 편만 저자가 확인되었습니다. 나머지 8편은 `authors` 가 비어 있어 화면에서 저자 줄이 생략되고 연구자 필터에도 잡히지 않습니다. `authors` 와 `members` 를 채우면 바로 반영됩니다.
2. **연락처**: 각 HTML 하단 푸터의 주소, 전화, 이메일. `project.contact` 도 함께 수정해 주십시오.
3. **연구팀 배치**: 연차보고서에는 2차년도 팀 구분(이공, 인문사회, 융합)과 팀별 일정만 있고 연구자별 배치는 명시되어 있지 않습니다. 전공과 담당 주제를 근거로 최승욱, 나형종, 안성희를 연구팀 2, 황인준과 김형준을 연구팀 1, 권오병과 김형준을 연구팀 3으로 넣어 두었습니다. 확인 후 `members[].teams` 와 `teams[].members` 를 조정해 주십시오.
4. **노승민 교수 관련**: 연구진 목록에서 제외했습니다. 다만 1차년도 학술대회 발표와 수상 기록에는 공저자로 남아 있습니다. 실제 발표 기록이라 그대로 두었으니, 빼실 경우 `conferences` 와 `awards` 의 해당 항목을 수정해 주십시오.

### 논문 추가

```js
{
  id: "j10",                       // 중복되지 않는 값
  title: "논문 제목",
  authors: "김철수, 이영희, 최승욱",  // 실제 저자 순서대로
  venue: "저널명, 권(호), 페이지",
  year: 2026,
  type: "SCIE",                    // SSCI | SCI | SCIE | ESCI | Scopus | KCI
  assistants: [   // 연구조원. name / affil / dept / course / track
    { name: "고풍", affil: "경희대학교 대학원", dept: "빅데이터응용학과", course: "박사과정", track: "mix" }
  ],
  members: ["최승욱"],              // 연구자 필터용
  metrics: "2025 IF 3.1, JCR Q1", // 선택 사항
  badge: "우수논문상",              // 선택 사항, 강조 표시
  abstract: "연구개요 원문"
}
```

## 4. 동작

- 연차 목표: 오늘 날짜 기준으로 진행 중인 연차에 보라색 표시가 붙습니다. 상단 메뉴 옆의 "2차년도 진행 중"도 같은 계산입니다
- 연구진 명부: 연구팀 필터, 행을 누르면 연구 분야와 역할이 펼쳐집니다
- 연구성과: 네 개 탭(게재논문, 주요 발표, 학술대회 발표, 수상), 통합 검색은 초록 본문까지 훑습니다. 연구자 선택과 정렬, 초록 일괄 펼치기를 지원합니다
- 딥링크: `publications.html?member=권오병` 은 해당 연구자만, `publications.html?tab=c` 는 학술대회 탭으로 열립니다
- 소식: 분류 필터, 6건 단위 페이지, 상세 창(ESC로 닫기)
- 키보드 조작 가능, 모바일 대응, `prefers-reduced-motion` 존중, 인쇄 시 초록 전체 노출

## 5. 보기와 배포

```bash
cd 이_폴더
python -m http.server 8080     # http://localhost:8080
```

`index.html` 을 그냥 더블클릭해도 열립니다. 정적 파일이므로 학교 웹서버 디렉터리에 그대로 올리면 됩니다.

폰트는 Google Fonts(Gowun Batang, IBM Plex Sans KR, IBM Plex Mono)를 CDN으로 불러옵니다. 교내망에서 막혀 있으면 폰트 파일을 받아 `assets/fonts` 에 두고 `@font-face` 로 바꿔 주십시오.

## 6. 사진 교체

`assets/img` 에 480×480 정사각 JPG로 넣고 `members[].photo` 경로를 맞추면 됩니다. 원본에서 얼굴이 위쪽 중앙에 오도록 정사각으로 잘라 두었습니다.

## 7. 색 바꾸기

`assets/css/style.css` 맨 위 `:root` 에서 한 번에 바꿉니다.

```css
--hs:  #c22e3a;   /* 인문사회 트랙 */
--sci: #1f3fc4;   /* 이공 트랙 */
--mix: #6a2f9e;   /* 두 트랙이 겹친 자리 */
--paper:#f1f1ed;  /* 바탕 */
--ink: #15171b;   /* 본문 */
```
